# DevFlow

DevFlow es una herramienta personal para ordenar el trabajo tecnico. La idea no es que sea “otro repo mas”, sino un sistema para pensar y ejecutar mejor: convertir tareas abiertas en pasos, guardar contexto, registrar decisiones y bajar la friccion cuando un proyecto empieza a crecer.

## Que problema toca

Cuando trabajo en varios proyectos a la vez, el problema no es solo escribir codigo. Tambien hay que recordar que se decidio, que falta, que se probo, que se rompio y cual es el siguiente paso razonable. DevFlow apunta a ordenar ese flujo.

## Como lo pienso

- Una herramienta para convertir ideas en tareas accionables.
- Un lugar para documentar avances sin depender de memoria suelta.
- Un flujo que pueda crecer hacia automatizacion, plantillas o comandos.
- Un proyecto donde Python sirve para operar, no solo para practicar.
