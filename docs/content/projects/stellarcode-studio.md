# StellarCode Studio

StellarCode Studio es una marca real lanzada al mercado. Es el espacio desde donde estoy empujando software, productos y servicios con una identidad propia.

## De que va

La idea es tener un estudio/lab desde donde pueda construir soluciones reales, presentar proyectos, trabajar con clientes o productos propios y mostrar una forma clara de hacer software: pensar el problema, disenar el flujo, construir la version y mejorarla.

Sitio publico: `https://stellarcodelabs.lat`

## Que representa

- Software real orientado al mercado, no solo ejercicios aislados.
- Documentacion visible de decisiones y aprendizajes.
- Un lugar para conectar marca personal, servicios, productos y proyectos futuros.
- Una forma de mostrar evolucion: de prototipo a producto, y de producto a oferta publica.

## Como puede crecer

StellarCode Studio puede crecer con casos de estudio, servicios, productos, plantillas, notas tecnicas y paginas especificas para cada solucion. Este portfolio debe funcionar como una capa personal que explica por que existe y que estoy construyendo alrededor.
