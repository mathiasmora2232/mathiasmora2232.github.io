# Como agregar un nuevo hito

Para sumar contenido no hace falta rehacer la pagina.

- Edita `docs/content/site-data.json`.
- Agrega un item en `timeline` para un hito cronologico.
- Agrega un item en `projects` para un nuevo proyecto.
- Crea un archivo Markdown en `docs/content/posts/` si quieres una nota nueva.
- Enlaza ese Markdown desde la seccion `notes`.

La regla editorial: escribir primero lo verificable, despues lo aprendido y al final lo que falta completar.
