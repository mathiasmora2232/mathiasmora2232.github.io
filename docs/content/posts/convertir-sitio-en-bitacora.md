# Convertir el sitio en bitacora viva

Este portfolio nace de una decision simple: no esconder la web universitaria antigua, sino archivarla y usar el dominio principal para contar una trayectoria en movimiento.

La pagina nueva separa contenido y presentacion. Los proyectos, hitos, experiencia, stack y notas viven en archivos editables. La interfaz solo los presenta.

- Si aparece un nuevo repo, se agrega al JSON.
- Si un proyecto gana historia, se escribe una nota Markdown.
- Si algo no esta verificado, se marca como pendiente en vez de inventarlo.

Ese criterio mantiene el sitio honesto y facil de ampliar.
